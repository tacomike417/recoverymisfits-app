Recovery Misfits Halloween Game - Starter Structure

FILES
-----
halloween-game.html
chapter0-intro.js
chapter1-story.js

ASSET FOLDERS
-------------
assets/cards/
assets/title/
assets/players/
assets/audio/
assets/collectibles/

NAMING RULE
-----------
Assets match the JS chapter name and sequence.

Examples:
assets/title/chapter0-intro-1.jpg
assets/title/chapter0-intro-2.jpg
assets/audio/chapter0-intro-music.mp3

assets/cards/chapter1-story-1.jpg
assets/cards/chapter1-story-2.jpg
assets/audio/chapter1-story-music.mp3

This is intentionally a lightweight starter. Gameplay files will be added later.
