# Sobered Up (Locked Up, Covered Up, or Sobered Up)
A Recovery Misfits game. Phone first (390 wide). Buildless: index.html + engine.js.

- `engine.js` — all rules, the 40 cards, and every tunable number (CFG at the top).
- `index.html` — the screens.
- `test.cjs` — `node test.cjs` runs 900 seeded chapters and regression checks.

Build order (from Sobered-Up-Game-Plan.md): 1 ✔ prototype gaps fixed · 2 ✔ heat meter + locked up · 3 paper doll + shop · 4 ladders + chapters · 5 relationships + phone in meetings · 6 ending + Keep Living · 7 balance pass.
